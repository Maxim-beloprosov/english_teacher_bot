# English Trainer Telegram Bot

Telegram-бот для изучения английского языка.

## Темы

- 📚 **Irregular Verbs** — неправильные глаголы, показываются все 3 формы.
- 🍎 **Food Vocabulary** — обычная лексика по теме еды (90+ слов).
- У каждой темы свой прогресс, ошибки и интервалы повторения.
- Неправильные ответы повторяются в конце урока.
- Сложные слова возвращаются по интервальному алгоритму.

## Запуск через Docker

1. Скопируйте `.env.example` в `.env`.
2. Укажите токен Telegram:

```env
BOT_TOKEN=ваш_токен
```

3. Настройте время:

```env
TIMEZONE=Europe/Moscow
LESSON_HOUR=9
LESSON_MINUTE=0
```

4. Укажите администратора. Можно username без `@`:

```env
ADMIN_USERNAME=my_username
ADMIN_USER_ID=0
```

Надёжнее дополнительно указать числовой Telegram ID:

```env
ADMIN_USER_ID=123456789
```

5. Запустите:

```bash
docker compose up -d --build
```

Проверка:

```bash
docker compose ps
docker compose logs -f
```

## Администратор

Админ видит кнопку **👑 Админ-панель**.

Доступные функции:

- 📊 статистика пользователей: количество пользователей, уроков и ответов;
- 📚 статистика словаря по темам;
- ➕ добавление новых слов прямо через Telegram;
- 📢 рассылка сообщения всем активным пользователям.

### Добавление слова

Для Food:

```text
food | apple | яблоко | I eat an apple.
```

Для неправильного глагола:

```text
irregular_verbs | go | идти | I go home. | went | gone
```

После добавления слово доступно в соответствующей теме.

### Важно про безопасность

`ADMIN_USERNAME` — удобный вариант, но Telegram username можно изменить. Для надёжного контроля лучше использовать `ADMIN_USER_ID`.

## База данных

SQLite хранится здесь:

```text
data/db/bot.db
```

Обычный `docker compose restart` / `docker compose down` не должен удалять этот файл. При переносе проекта копируйте **всю папку `data/db`**, если хотите сохранить прогресс.

Версия проекта содержит автоматическую миграцию старой базы: существующие слова получают категорию `irregular_verbs`, а новые поля добавляются без удаления существующих данных.
